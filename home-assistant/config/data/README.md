# Data Directory

This directory contains **runtime data, logs, and cache files** generated by automations and scripts. These files should NOT be mixed with configuration or script definitions.

## Structure

```tree
data/
├── alexa/                 # Alexa Smart Home integration data
│   └── developer.amazon.com.har    # HAR export for debugging
└── [future services]/     # Add directories as needed for other services
```

## Purpose

Separates operational data from configuration:

- **Configuration** (`/config/*.yaml`) - How things work
- **Scripts** (`/config/scripts/`) - Script definitions
- **Data** (`/config/data/`) - What things generate (logs, cache, exports)

## Usage Guidelines

### ✅ What Goes Here

- Log files from automations
- Progress/status files
- Cache files
- Export files (HAR, JSON, CSV, etc.)
- Temporary data
- Service-specific runtime data

### ❌ What Does NOT Go Here

- YAML configuration files → `/config/`
- Script definitions → `/config/scripts/`
- Documentation → `/config/docs/`
- Templates → `/config/templates/`

## Gitignore Recommendations

Consider adding to `.gitignore`:

```tree
# Runtime data (optional - exclude from git)
data/**/*.log
data/**/*.json
data/**/*.har
data/**/*.tmp
```

Keep directory structure but ignore generated files if desired.

## Backup Considerations

When backing up Home Assistant config:

- **Always backup:** `/config/*.yaml`, `/config/scripts/`, `/config/automations/`
- **Optional:** `/config/data/` (can be regenerated)
- **Never backup:** `/config/.storage/` (HA manages internally)
